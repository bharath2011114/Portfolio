# Portfolio Website (Assignment)

## Description

This project is a portfolio website developed as part of an academic assignment.
It demonstrates the use of HTML and CSS to design a structured, visually appealing, and responsive web page.

The website presents personal details, academic background, and projects in an organized and user-friendly format.

---

## Objective

The main objectives of this project are:

* To design and develop a portfolio website using HTML and CSS
* To implement multiple sections with smooth navigation
* To present academic details and projects clearly
* To create a clean, modern, and responsive user interface

---

## Technologies Used

* HTML5
* CSS3
* Font Awesome (for icons)

---

## Key Features

* Fixed navigation bar with smooth scrolling between sections
* Responsive home section with profile image and introduction
* Well-structured About section with education and goals
* Resume section with academic details and skills
* Projects section with card-based layout and GitHub links
* Contact section with fully clickable cards
* Responsive design implemented using Flexbox and Grid

---

## Website Sections

### Home

Provides an introduction, name, and navigation buttons for quick access to different sections.

### About

Displays educational background, areas of interest, and career objectives.

### Resume

Includes academic qualifications and basic technical skills.

### Projects

The following projects are included:

* **Library Management System**
* **Smart Adaptive Traffic Light System**
* **Mini Web Projects**

Each project is displayed using cards and includes a link to the corresponding GitHub repository.

### Contact

Shows contact details such as email, GitHub, LinkedIn, and location in a structured layout.

---

## How to Run the Project

1. Clone or download the repository
2. Open the `index.html` file in any web browser
